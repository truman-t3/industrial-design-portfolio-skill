# Code of Conduct · 行为准则

## Our pledge · 我们的承诺

We pledge to make participation in this project a harassment-free experience for everyone, regardless of background, identity, experience, or level of expertise.

我们承诺为所有参与者提供不受骚扰的协作环境，不因背景、身份、经验或专业水平而区别对待。

## Expected behavior · 期望行为

- Be respectful, specific, and constructive.
- Critique artifacts and decisions rather than people.
- Protect private project evidence and personal information.
- Disclose generated or synthetic material honestly.
- Accept correction and help maintain a welcoming environment.

- 保持尊重、具体和建设性。
- 讨论作品与决策，不攻击个人。
- 保护私密项目证据与个人信息。
- 如实披露生成或虚构素材。
- 接受纠正，共同维护友好的协作环境。

## Unacceptable behavior · 不可接受行为

Harassment, discrimination, threats, publication of private information, deliberate evidence fabrication, and sustained disruptive behavior are not accepted.

不接受骚扰、歧视、威胁、公开私人信息、故意伪造证据或持续扰乱协作的行为。

## Enforcement · 执行

Report conduct concerns privately to the repository owner through their GitHub profile. The maintainer may remove content, restrict participation, or take other proportionate action. Reports will be handled as confidentially as reasonably possible.

请通过仓库维护者的 GitHub 主页私下报告行为问题。维护者可以删除内容、限制参与或采取其他适当措施，并会在合理范围内对报告保密。

This project adopts the intent of the Contributor Covenant 2.1 while keeping this repository-specific summary concise.
