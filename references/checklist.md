# Portfolio Quality Checklist

## P0 — credibility blockers

- [ ] No fabricated research, tests, measurements, costs, patents, or outcomes.
- [ ] AI-generated visuals are disclosed and not presented as evidence.
- [ ] Personal role and team authorship are stated for every project.
- [ ] Technical drawings come from consistent geometry or are labeled conceptual.
- [ ] Confidential or personal information is removed or authorized.
- [ ] Every decisive claim has evidence, a citation, or an assumption label.

## P1 — comprehension and usability

- [ ] The target role/audience is evident in the first two pages.
- [ ] Every project has a one-sentence thesis.
- [ ] Problem, decision, iteration, and result can be found quickly.
- [ ] All slides use a registered `data-layout` ID.
- [ ] No placeholder tokens remain.
- [ ] Images have alt text and evidence captions where required.
- [ ] Body text and captions remain legible at presentation distance.
- [ ] Navigation works with keyboard, controls, touch, and reduced motion.
- [ ] No content overlaps the bottom safe area.

## P2 — design quality

- [ ] One dominant idea per page.
- [ ] Page rhythm alternates evidence density and synthesis.
- [ ] Repeated layout structures are intentional.
- [ ] Image crops preserve evidence and scale cues.
- [ ] Comparison images use matched scale and framing.
- [ ] Accent color is used for decisions and navigation, not decoration.
- [ ] Captions are visually attached to the correct image.
- [ ] Final imagery does not overwhelm the design process.

## P3 — refinement

- [ ] File names are semantic and ordered.
- [ ] Sources, dates, units, and currencies use consistent formatting.
- [ ] Project numbering, labels, and capitalization are consistent.
- [ ] PDF print rules hide browser controls and preserve page bounds.
- [ ] The final page includes contact information and relevant links.

## Delivery gate

Deliver only when all P0 and P1 items pass. Report remaining P2/P3 issues as optional polish, not silent omissions.
