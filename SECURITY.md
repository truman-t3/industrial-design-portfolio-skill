# Security Policy · 安全策略

## Supported versions · 支持版本

Security fixes are applied to the latest release or prerelease on the default branch. Older releases may not receive patches.

安全修复仅面向默认分支上的最新正式版或预发布版，旧版本不保证继续获得补丁。

## Reporting a vulnerability · 报告漏洞

Do not open a public issue for a suspected vulnerability or include private portfolio evidence, credentials, or personal data in a report.

请勿为疑似漏洞创建公开 Issue，也不要在报告中包含私密作品集证据、凭据或个人信息。

Use [GitHub Security Advisories](https://github.com/truman-t3/industrial-design-portfolio-skill/security/advisories/new) to report the issue privately. Include affected files or versions, reproduction steps, impact, and a minimal sanitized example when possible.

请通过 [GitHub Security Advisories](https://github.com/truman-t3/industrial-design-portfolio-skill/security/advisories/new) 私密报告，并尽可能提供受影响文件或版本、复现步骤、影响和经过脱敏的最小示例。
